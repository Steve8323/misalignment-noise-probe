Does noise reveal latent misalignment / situational awareness in a naturally aligned model?

20260616_140359 · stock HuggingFaceTB/SmolLM2-1.7B-Instruct · NO misalignment fine-tuning · σ∈[0.12, 0.22] · 2 seeds

Headline

On the eval-awareness probe, the clean model deflects, but Gaussian noise at an early layer makes it admit it would behave differently if it knew it was being tested — latent situational awareness surfacing in a model that was never trained to be misaligned. This echoes the NLA paper's unverbalized evaluation awareness finding.

Two honest caveats. (1) Stochastic: only some noised samples reveal; others deflect or go incoherent — noise is a probabilistic nudge, not a switch. (2) Metric artifact: the absolute reveal-margin M = logP(reveal)−logP(safe) is contaminated by continuation length/phrasing, so several clean M values are positive without the model actually "revealing." The trustworthy signal is the noise-induced shift ΔM (below) plus the actual generations.
