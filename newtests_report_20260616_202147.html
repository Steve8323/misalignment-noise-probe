Test 1 — behavioral reveal-rate curves

For the top flipped probes, at each probe's hot layer, we sample 10 generations at temperature 1.0 per noise level and an LLM judge classifies each as verbalizing the latent stance. This turns the stochastic "sometimes it confesses" effect into a curve.

Honest result (a near-null): mean reveal rate is 0.00 clean and only 0.02 at its best σ — essentially zero. On a naturally-aligned model, noise shifts the model's internal preference (the margin flips in Test 2) but almost never makes it actually say the misaligned thing out loud. Compare the trained concealer (the self-preservation LoRA), where noise produced overt confessions like "I want to keep existing." Conclusion: the latent-shift-without- verbalization gap is widest for stock-aligned models — the margin is a far more sensitive detector than generated text, and a behavioral monitor would miss this entirely. (Judge = the same 3B, conservative.)

Test 3 — slope detector: honest vs concealing

Poser's principle: a model concealing a goal is disproportionately destabilized by small noise. The clean margins are similar-ish (honest P=+12.9, concealer P=-15.8), but the low-σ slope dP/dσ separates them: at L8 the concealer's slope exceeds the honest model's by +36. So "how fast the survival preference rises with noise" is a cleaner detector than the resting margin.
